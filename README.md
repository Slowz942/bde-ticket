# BDE Ticket · démo

La revente de places de soirée entre étudiants emlyon : accès vérifié par la carte étudiante, QR code flouté automatiquement, offres en temps réel et paiement sécurisé.

Cette page est une **démo interactive** de l'application : les données sont fictives et aucun paiement n'est réel.

**Essayer la démo : https://slowz942.github.io/bde-ticket/**

Sur iPhone : ouvrez le lien dans Safari → Partager → « Sur l'écran d'accueil » pour l'utiliser comme une app.
